# Course 13 ⭐ — Mastering Flutter UI

**Tier 2 · Frameworks & Specialisation · Level: Intermediate · Prerequisites: Course 11 · TOP FEATURED**

Users judge apps in three seconds. This course is a pure UI gym: 30 focused workouts
that clone real interfaces (Instagram, Twitter, Telegram) and master every important
widget — until beautiful screens come out of your fingers naturally.

**What you will learn**

- Recreate famous app interfaces pixel by pixel
- Every core UI widget: sheets, dialogs, lists, grids, tabs, drawers
- Complete screen patterns: login, profile, e-commerce, dashboard, settings

## Final project

Design a complete **5-screen app UI** for a business you invent (onboarding, login,
home feed, detail, profile/settings). Must use: bottom navigation, cards, a dialog, a
swipe list and a themed color scheme. Submit screenshots + code.

**Quiz ideas:** widget identification from screenshots · "which widget would you
use?" scenarios · layout-order puzzles · project graded on visual checklist.
