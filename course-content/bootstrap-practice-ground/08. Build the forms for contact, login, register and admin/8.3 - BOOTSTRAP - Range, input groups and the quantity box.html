Lesson 8.3

Range, input groups and the quantity box

How it works

A range input lets a person select a value along a scale. An input group places related text, buttons or inputs together.

Example

Choose a quantity and unit

bags

Code for this example

HTML

<div class="mb-3">
  <label class="form-label" for="quantity">
    Quantity
  </label>
  <input class="form-range" type="range" min="1" max="10" value="2" id="quantity">
</div>
<label class="form-label" for="qtyBox">
  Rice, 5 kg
</label>
<div class="input-group" style="max-width:20rem">
  <button class="btn btn-outline-secondary" type="button" aria-label="Decrease quantity">
    −
  </button>
  <input id="qtyBox" class="form-control text-center" type="number" min="1" value="1">
  <span class="input-group-text">
    bags
  </span>
  <button class="btn btn-outline-secondary" type="button" aria-label="Increase quantity">
    +
  </button>
</div>

When should you use this?

Use a quantity input group for a product amount or a range when a value can be chosen along a scale.

Key points

  • Set sensible min, max and starting values.
  • Label every input.
  • Buttons beside an input need clear names and working behavior.

In short

Controls need a clear label, a useful range and predictable behavior.

Try it yourself

Add minus and plus behavior only if you know the small JavaScript needed. Keep min and accessible names.
