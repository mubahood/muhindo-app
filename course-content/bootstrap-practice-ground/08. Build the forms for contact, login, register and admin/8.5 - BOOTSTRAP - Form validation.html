Lesson 8.5

Form validation

How it works

Browser validation checks common rules such as required fields and valid email addresses. Bootstrap styles the valid and invalid states.

Example

Let the browser explain a missing field

Enter a valid email address.

Code for this example

HTML

<form class="needs-validation" novalidate>
  <label class="form-label" for="requiredEmail">
    Email address
  </label>
  <input class="form-control" id="requiredEmail" type="email" required>
  <div class="invalid-feedback">
    Enter a valid email address.
  </div>
  <button class="btn btn-primary mt-3" type="submit">
    Send
  </button>
</form>

Check the form on submit

const forms = document.querySelectorAll(".needs-validation");

forms.forEach(form => {
  form.addEventListener("submit", event => {
    if (!form.checkValidity()) {
      event.preventDefault();
    }
    form.classList.add("was-validated");
  });
});

When should you use this?

Use validation on forms to help people correct missing or wrongly formatted information before submission.

Key points

  • Use HTML attributes such as required and type=email.
  • Show a clear message near an invalid field.
  • Client-side validation does not replace server-side checks.

In short

Validation should explain how to fix an error, not only show that one exists.
