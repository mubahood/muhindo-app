Lesson 8.4

Floating labels and the login page

How it works

A floating label sits inside an input when it is empty and moves above it when someone enters a value.

Example

Build a compact login form

Code for this example

HTML

<div class="form-floating mb-3">
  <input class="form-control" id="loginEmail" type="email" placeholder="name@example.test">
  <label for="loginEmail">
    Email address
  </label>
</div>
<div class="form-floating">
  <input class="form-control" id="loginPassword" type="password" placeholder="Password">
  <label for="loginPassword">
    Password
  </label>
</div>
<button class="btn btn-primary w-100 mt-3" type="button">
  Sign in
</button>

When should you use this?

Use floating labels when a compact form needs to show its field name clearly.

Key points

  • The input needs a placeholder for the floating label pattern.
  • The label for value must match the input id.
  • Keep enough contrast and space for the label.

In short

A compact form can still have labels that remain visible and readable.

Try it yourself

Add a remember-me checkbox and a link to register. Give each input a unique id.
