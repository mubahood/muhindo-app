Lesson 8.2

Selects, checkboxes, radios and switches

How it works

Selects, checkboxes, radios and switches let people choose values. Each control is best for a different kind of choice.

Example

Offer clear choices

Preferred contact

Code for this example

HTML

<fieldset>
  <legend class="fs-6">
    Preferred contact
  </legend>
  <div class="form-check">
    <input class="form-check-input" type="radio" name="contact" id="contactEmail" checked>
    <label class="form-check-label" for="contactEmail">
      Email
    </label>
  </div>
  <div class="form-check">
    <input class="form-check-input" type="radio" name="contact" id="contactPhone">
    <label class="form-check-label" for="contactPhone">
      Phone
    </label>
  </div>
  <div class="form-check form-switch mt-3">
    <input class="form-check-input" type="checkbox" role="switch" id="offers">
    <label class="form-check-label" for="offers">
      Send me shop updates
    </label>
  </div>
</fieldset>

When should you use this?

Use radio buttons for one choice from a short list, checkboxes for choices that can be combined, and a select for a longer list.

Key points

  • Group related controls in a fieldset with a legend.
  • Connect each label to its control.
  • A switch represents an on or off setting.

In short

Choose the control that matches the kind of choice the person must make.
