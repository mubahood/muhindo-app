Lesson 8.1

Form controls and form layout

How it works

Bootstrap form classes style labels, text fields and buttons. HTML labels explain each field and connect to it.

Example

Label every form control

Code for this example

HTML

<form>
  <div class="mb-3">
    <label class="form-label" for="customerName">
      Your name
    </label>
    <input class="form-control" id="customerName" name="name" autocomplete="name" placeholder="Amina Example">
  </div>
  <div class="mb-3">
    <label class="form-label" for="customerEmail">
      Email
    </label>
    <input class="form-control" id="customerEmail" name="email" type="email" autocomplete="email" placeholder="amina@example.test">
  </div>
  <button class="btn btn-primary" type="button">
    Continue
  </button>
</form>

When should you use this?

Use a form when someone needs to send information, such as a contact message or delivery address.

Key points

  • Every field needs a clear label.
  • Match the label for value to the input id.
  • Use a useful type, name and autocomplete value.

In short

A form is easier to use when every field has a clear purpose and label.
