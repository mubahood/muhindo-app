Lesson 5.5

Pagination and list groups

How it works

A list group styles related list items. Pagination gives people links between pages of results.

Example

Group categories and page links

  • All products
  • Groceries
  • Home care
  • 1
  • 2

Code for this example

HTML

<ul class="list-group mb-3">
  <li class="list-group-item active" aria-current="true">
    All products
  </li>
  <li class="list-group-item">
    Groceries
  </li>
  <li class="list-group-item">
    Home care
  </li>
</ul>
<nav aria-label="Product pages">
  <ul class="pagination mb-0">
    <li class="page-item active">
      <a class="page-link" href="#" aria-current="page">
        1
      </a>
    </li>
    <li class="page-item">
      <a class="page-link" href="#">
        2
      </a>
    </li>
  </ul>
</nav>

When should you use this?

Use a list group for categories or settings. Use pagination when a long set of results is split into pages.

Key points

  • Mark the current page with active and aria-current.
  • Give pagination a descriptive navigation label.
  • Use list groups for related items, not every list on a page.

In short

Make the current selection and page easy to identify.

Try it yourself

Add one category and one page. Label the pagination navigation for screen readers.
