Lesson 5.6

Cards and the product grid

How it works

A card groups related content, often an image, title, description and action. Cards can be arranged in a responsive grid.

Example

Make a simple product card

Rice, 5 kg

A pantry staple for family meals.

$8.00

Code for this example

HTML

<div class="card h-100" style="max-width:20rem">
  <img src="../images/products/rice-5kg.webp" class="card-img-top" alt="A bag of rice">
  <div class="card-body">
    <h3 class="h5 card-title">
      Rice, 5 kg
    </h3>
    <p class="card-text">
      A pantry staple for family meals.
    </p>
    <div class="d-flex justify-content-between align-items-center">
      <strong>
        $8.00
      </strong>
      <button class="btn btn-sm btn-primary">
        Add
      </button>
    </div>
  </div>
</div>

When should you use this?

Use a card for a product or another item that needs a repeated, self-contained layout.

Key points

  • Use a real heading for the card title.
  • Use h-100 when cards in a row should stretch to equal height.
  • Keep card actions clear and consistent.

In short

Build one useful card first, then repeat the same structure for other items.

Try it yourself

Duplicate the card inside a responsive row. Keep each card the same height.
