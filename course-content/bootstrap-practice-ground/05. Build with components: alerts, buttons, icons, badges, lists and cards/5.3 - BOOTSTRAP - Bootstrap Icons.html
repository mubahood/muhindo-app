Lesson 5.3

Bootstrap Icons

How it works

Bootstrap Icons is a separate icon font and SVG set. It works alongside Bootstrap, but it has its own file and icon names.

Example

Add an icon without hiding its meaning

Code for this example

Load the icon stylesheet

<link rel="stylesheet" href="../css/vendor/bootstrap-icons.min.css">

Use an icon beside its meaning

<button class="btn btn-outline-primary">
  <i class="bi bi-basket3 me-2" aria-hidden="true">
  </i>
  <span>
    Add to cart
  </span>
</button>

When should you use this?

Use an icon to support a short label, such as a basket beside Add to cart.

Key points

  • Load the Bootstrap Icons stylesheet.
  • Use the exact icon name from its documentation.
  • Give an icon-only control an accessible name.

In short

An icon should help explain a control, not make its meaning harder to find.

Try it yourself

Try another Bootstrap Icon name. Keep visible text or an accessible name for icon-only buttons.
