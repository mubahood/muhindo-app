Lesson 5.4

Badges, progress bars and spinners

How it works

Badges show a short status or count. Progress bars show how much of a task is complete. Spinners signal that a wait is happening.

Example

Show order progress

Preparing your order In progress

65%

Loading recent orders...

Code for this example

HTML

<p>
  Preparing your order
  <span class="badge text-bg-primary">
    In progress
  </span>
</p>
<div class="progress mb-3" role="progressbar" aria-label="Order progress" aria-valuenow="65" aria-valuemin="0" aria-valuemax="100">
  <div class="progress-bar" style="width:65%">
    65%
  </div>
</div>
<p>
  <span class="spinner-border spinner-border-sm me-2" aria-hidden="true">
  </span>
  <span role="status">
    Loading recent orders...
  </span>
</p>

When should you use this?

Use a badge for order status, a progress bar for a known amount of progress, and a spinner while content loads.

Key points

  • Keep badge text short.
  • Set the progress width and aria-valuenow to the same value.
  • Explain a spinner to assistive technology.

In short

Choose the status component that matches the information you need to show.

Try it yourself

Change both the progress width and aria-valuenow to the same number. Then try the spinner beside a short loading message.
