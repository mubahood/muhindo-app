Lesson 5.2.1

Buttons and button groups, advanced

How it works

A button group can hold more than plain buttons. With a checkbox or radio input and a label styled as a button, the group becomes a control that remembers what is selected, which is how filter bars and size pickers are built.

Example

A size picker made from radios

Code for this example

HTML

<div class="btn-group" role="group" aria-label="Size">
  <input type="radio" class="btn-check" name="size" id="s1" checked>
  <label class="btn btn-outline-primary" for="s1">S</label>
  <input type="radio" class="btn-check" name="size" id="s2">
  <label class="btn btn-outline-primary" for="s2">M</label>
</div>

When should you use this?

Use a radio group when exactly one choice applies, such as a size or a sort order. Use checkboxes in a group when several can apply at once, such as filters.

Key points

  • btn-check hides the input and lets the label carry the styling.
  • Every input needs an id and its label a matching for attribute.
  • Radios sharing a name allow one choice; checkboxes allow several.
  • btn-group-vertical stacks the same group on narrow screens.

In short

A button group with inputs inside it is a real form control, not just a row of buttons.
