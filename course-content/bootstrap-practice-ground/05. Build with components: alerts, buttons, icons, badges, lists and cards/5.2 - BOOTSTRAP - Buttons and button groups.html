Lesson 5.2

Buttons and button groups

How it works

Bootstrap button classes give buttons a consistent style. Button groups keep related actions together.

Example

Choose a button for each action

Code for this example

HTML

<div class="d-flex flex-wrap gap-2">
  <button class="btn btn-primary">
    Add to cart
  </button>
  <button class="btn btn-outline-secondary">
    Save for later
  </button>
  <div class="btn-group" role="group" aria-label="Choose a view">
    <button class="btn btn-outline-primary">
      Grid
    </button>
    <button class="btn btn-outline-primary">
      List
    </button>
  </div>
</div>

When should you use this?

Use one clear primary button for the main action and quieter styles for secondary actions.

Key points

  • Use a button element for an action.
  • Use an anchor for navigation.
  • Group buttons only when the actions belong together.

In short

Make the main action easy to find and name each action clearly.

Try it yourself

Use a filled button for the main action and an outline button for the secondary action.
