Lesson 5.1

Alerts

How it works

An alert is a message set apart from the rest of the page. It can explain success, a warning or another status.

Example

Show a delivery message

Good news! Delivery is free on orders over $30.

Code for this example

HTML

<div class="alert alert-success alert-dismissible fade show" role="alert">
  <strong>
    Good news!
  </strong>
  Delivery is free on orders over $30.
  <button type="button" class="btn-close" data-bs-dismiss="alert" aria-label="Close">
  </button>
</div>

When should you use this?

Use an alert for a message that people need to notice, such as a delivery update or form result.

Key points

  • Choose a contextual alert class.
  • Use role=alert only for messages that need an immediate announcement.
  • A dismiss button needs an accessible name.

In short

Keep alerts brief and use them for messages that matter.

Try it yourself

Change the alert colour and dismiss it with the close button.
