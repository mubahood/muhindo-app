Lesson 11.2

Module 11 quiz

Example

Answer each question in your own words. Check the notes after you finish.

  1. Why do you write one brief instead of twenty small prompts?
    • a) It uses fewer tokens
    • b) The assistant can see the whole site at once, so the pages come back consistent with each other
    • c) Small prompts are not allowed
    • d) It is faster to type
  2. Why must you name the Bootstrap version in your house rules?
    • a) Otherwise nothing loads
    • b) Assistants fall back on Bootstrap 4 habits such as data-toggle, ml and mr unless you stop them
    • c) The CDN requires it
    • d) Version 5.3 is the only one that works
  3. You ask for custom CSS in its own file rather than inline styles. Why?
    • a) Inline styles are slower
    • b) A separate file can be read, reviewed and changed in one place; inline styles hide the design in the markup
    • c) GitHub Pages blocks inline styles
    • d) Bootstrap forbids it
  4. What must your home page be called for GitHub Pages to serve it?
    • a) home.html
    • b) default.html
    • c) index.html, in lower case, at the root of what you publish
    • d) Any name, if you set it in the settings
  5. A page in your admin folder works locally and loses its stylesheet once published. What is the likely cause?
    • a) GitHub Pages does not allow subfolders
    • b) The page is one folder down and the link is missing ../
    • c) Bootstrap must be installed
    • d) The CSS file is too large
  6. An image shows on your Mac but is missing on the live site. What should you check first?
    • a) The image is too large
    • b) The file name case: GitHub is case sensitive, so Hero.JPG is not hero.jpg
    • c) The alt text
    • d) The img-fluid class
  7. What is the habit the course ends on?
    • a) Write better prompts
    • b) Use AI only for small things
    • c) The assistant drafts, you check the version and the classes, you test at three widths, and your name goes on the result
    • d) Avoid AI for layout
Show answer notes
  1. b. Pages briefed separately drift apart: different navbars, different spacing, different tone.
  2. b. Say it out loud in the rules and it stops being a problem.
  3. b. You cannot review what you cannot find, and inline styles are scattered through every file.
  4. c. Any other name gives you a file listing or a 404.
  5. b. Paths from a subfolder have to go up a level first. The commonest publishing bug there is.
  6. b. Your laptop ignores case. The server does not.
  7. c. Useful and accountable at the same time, which is the whole course in one line.

Try it yourself

Before you answer, open the live site you published in lesson 11.1 and check it against questions 4, 5 and 6. If any of the three catches you out, fix it, push again, and then come back to the quiz.
