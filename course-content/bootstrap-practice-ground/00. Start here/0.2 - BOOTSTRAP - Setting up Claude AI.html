Lesson 0.2

Setting up Claude AI

How it works

Claude is the second assistant used on this course, alongside Copilot. You create a free account, start a project for your website, and give the project the files you are working on so its answers match your own code instead of a generic example.

Example

What a project gives you

  • A place that remembers the website you are building
  • Your HTML and CSS files, so answers use your class names
  • House rules the assistant follows in every reply

Code for this example

HTML

Project: Marigold Stores

House rules:
- Bootstrap 5.3 only, loaded from the CDN
- No custom CSS unless I ask for it
- Mobile first, test at 360px
- Explain any class I have not met yet

When should you use this?

Set this up before Module 10. From there on the course asks you to brief an assistant once and then build whole pages from that brief, and a project with your files in it is what makes that work.

Key points

  • A free account is enough for everything on this course.
  • A project keeps your files and your house rules in one place.
  • House rules written once save you repeating yourself every prompt.
  • The four checks from Lesson 2.4 still apply to everything it writes.

In short

Set the project up now, and the AI modules later in the course will work on your code rather than someone else's.

Try it yourself

Create a project, name it after your site, and write three house rules of your own in it.
