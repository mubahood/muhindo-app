Lesson 1.6

Add Bootstrap 5.3 from the jsDelivr CDN

How it works

Bootstrap CSS provides its classes. The JavaScript bundle powers interactive components such as dropdowns and modals. The bundle also includes Popper for positioned components.

Load Bootstrap from the CDN

<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/css/bootstrap.min.css" rel="stylesheet" integrity="sha384-sRIl4kxILFvY47J16cr9ZwB07vP4J8+LH7qKQnuqkuIAvNWLzeN8tE5YBujZqJLB" crossorigin="anonymous">
<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/js/bootstrap.bundle.min.js" integrity="sha384-FKyoEForCGlyvwx9Hj09JcYn3nv7wiPVlz7YYwJrWVcXK/BmnVDxM+D2scQbITxI" crossorigin="anonymous">
</script>

Or load the included local files

<link rel="stylesheet" href="../css/vendor/bootstrap.min.css">
<script src="../js/vendor/bootstrap.bundle.min.js">
</script>

When should you use this?

Use CDN links when your project can load files from the internet. Use local files when you need the project to work offline.

Key points

  • Load Bootstrap CSS in the head.
  • Load the Bootstrap bundle near the end of the body.
  • Use the same Bootstrap version for the CSS and JavaScript.
  • Bootstrap 5 does not need jQuery.

In short

Correct file paths and matching versions let Bootstrap styles and interactive components work.
