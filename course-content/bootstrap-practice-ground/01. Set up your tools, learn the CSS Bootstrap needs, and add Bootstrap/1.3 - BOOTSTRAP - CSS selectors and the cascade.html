Lesson 1.3

CSS selectors and the cascade

How it works

A CSS selector chooses which HTML elements a rule changes. The cascade decides which matching rule wins when more than one rule applies.

Example

See which CSS rule wins

This paragraph matches the element and class rules.

This paragraph also matches the id rule.

This paragraph uses a Bootstrap color utility.

Code for this example

HTML

<div class="selector-cascade-example">
  <p class="selector-example">
    This paragraph matches the element and class rules.
  </p>
  <p id="special-example" class="selector-example">
    This paragraph also matches the id rule.
  </p>
  <p class="selector-example text-success">
    This paragraph uses a Bootstrap color utility.
  </p>
</div>

CSS

p { color: #345; }
.selector-example { color: #17633c; }
#special-example { color: #9a3e14; }

When should you use this?

Use a class selector for reusable styles. Use an id selector only when the page needs to identify one unique element.

Key points

  • A class selector starts with a dot in CSS.
  • An id selector starts with # in CSS.
  • If two rules have equal specificity, the later rule wins.
  • Bootstrap utility classes can override ordinary rules, so remove a utility when you no longer need it.

In short

Check the selector and the winning rule in DevTools when a style does not look right.

Try it yourself

Change one selector at a time. Use DevTools to see which matching rule wins and why.
