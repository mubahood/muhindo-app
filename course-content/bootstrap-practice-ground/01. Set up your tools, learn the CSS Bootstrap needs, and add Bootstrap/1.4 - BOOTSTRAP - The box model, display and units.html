Lesson 1.4

The box model, display and units

How it works

Every element is a box made of content, padding, border and margin. The display value controls how the box takes part in a line. CSS units set its size. With content-box, padding and border are added outside the width. With border-box, they fit inside it.

Example

Compare boxes, display and units

1. The box model

content-box
width: 12rem
border-box
width: 12rem

Each box is set to 12rem. Padding and border add to the outside of the content-box. They fit inside the border-box.

2. Display

A block starts a new line: block item then the next line.

Inline items stay in the sentence: before inline item after.

Inline-block stays in the line but accepts a width: 8rem wide beside this text.

3. Units

This text is 1.5rem (30px here).

This text is 24px.

When should you use this?

Use border-box when you need a box to stay within a planned width. Use block for page sections, inline for text, and inline-block for small items that need a set size. Use rem for text and spacing that should scale with the root font size.

Key points

  • The box model order is content, padding, border, margin.
  • A 12rem content-box with padding and a border is wider than 12rem.
  • A 12rem border-box stays 12rem wide including padding and border.
  • At the browser default, 1rem is usually 16px. This page sets the root size to 20px, so 1.5rem is 30px.

In short

Choose box-sizing, display and units deliberately. They explain how large an element is and where it sits.

Try it yourself

Change the padding and border and compare the outside widths. Then switch one display value and compare 1.5rem with 24px. Keep the viewport narrow and look for overflow.
