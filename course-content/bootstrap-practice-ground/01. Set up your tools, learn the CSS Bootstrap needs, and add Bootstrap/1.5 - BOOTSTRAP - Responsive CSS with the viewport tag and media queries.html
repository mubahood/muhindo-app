Lesson 1.5

Responsive CSS with the viewport tag and media queries

How it works

A responsive page changes its layout to fit the screen. The viewport tag tells a phone to use its real screen width. A media query applies CSS only at chosen widths.

Example

Resize the page

First box: on a phone, this takes the full line.

Second box: from 768px, both boxes share a row.

Code for this example

HTML

<meta name="viewport" content="width=device-width, initial-scale=1">
<div class="responsive-pair">
  <p>
    First box: on a phone, this takes the full line.
  </p>
  <p>
    Second box: from 768px, both boxes share a row.
  </p>
</div>

CSS

.responsive-pair {
  display: grid;
  grid-template-columns: 1fr;
  gap: 1rem;
}

@media (min-width: 768px) {
  .responsive-pair {
    grid-template-columns: repeat(2, minmax(0, 1fr));
  }
}

When should you use this?

Use a media query when a layout needs to change at a breakpoint, such as moving from one column on a phone to two on a larger screen.

Key points

  • Start with the phone layout, then add wider-screen rules.
  • The viewport tag belongs in the head.
  • Flexible images should not grow beyond their parent.

In short

Build for a small screen first, then add changes only where the wider screen needs them.

Try it yourself

Resize the browser. Change the breakpoint in the media query, then see where the boxes move.
