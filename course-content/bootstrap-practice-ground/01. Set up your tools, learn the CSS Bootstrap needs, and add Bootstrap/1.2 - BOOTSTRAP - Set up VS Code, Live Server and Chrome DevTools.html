Lesson 1.2

Set up VS Code, Live Server and Chrome DevTools

How it works

A project is a group of related files. Open the whole folder in VS Code so the editor can find its CSS, JavaScript and images.

Example

When should you use this?

Use Live Server while you build pages. It opens your site at a web address and refreshes after you save.

Key points

  • Open the project folder, not only one HTML file.
  • Use DevTools to inspect elements, styles and errors.
  • Test a page at phone, tablet and laptop widths.

In short

A clear project folder and a browser preview make it easier to find and fix problems.
