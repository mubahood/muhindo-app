How it works

Bootstrap is a collection of CSS classes and JavaScript tools. You add those classes to HTML to style common page parts quickly.

Example

Start with one small page

Marigold Stores

A friendly neighbourhood shop

Useful things for home, school and everyday life.

Code for this example

HTML

<div class="p-4 bg-light rounded-3">
  <p class="text-uppercase small text-secondary mb-2">
    Marigold Stores
  </p>
  <h2 class="h3">
    A friendly neighbourhood shop
  </h2>
  <p class="mb-3">
    Useful things for home, school and everyday life.
  </p>
  <button class="btn btn-primary">
    Shop now
  </button>
</div>

When should you use this?

Use Bootstrap when you want a responsive starting point for common page layouts and controls.

Key points

  • Bootstrap does not replace HTML.
  • Bootstrap does not stop you from writing your own CSS.
  • The examples in this course use Bootstrap 5.3.

In short

Bootstrap gives you ready-made styles and behavior. You still decide what the page says and how it should work.
