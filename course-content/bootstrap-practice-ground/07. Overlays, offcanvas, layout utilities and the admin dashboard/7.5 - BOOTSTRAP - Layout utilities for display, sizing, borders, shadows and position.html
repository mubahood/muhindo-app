Lesson 7.5

Layout utilities for display, sizing, borders, shadows and position

How it works

Bootstrap utility classes set one small style, such as display, width, border, shadow or position.

Example

Use utilities to refine a card

New

Featured item

A light shadow and border help this card stand out.

Code for this example

HTML

<div class="position-relative border rounded p-4 shadow-sm">
  <span class="position-absolute top-0 end-0 translate-middle badge rounded-pill text-bg-danger">
    New
  </span>
  <h3 class="h5">
    Featured item
  </h3>
  <p class="mb-0">
    A light shadow and border help this card stand out.
  </p>
</div>

When should you use this?

Use utilities for quick adjustments that do not need a reusable custom rule.

Key points

  • Utilities are added to the HTML class attribute.
  • Responsive utility variants apply at selected breakpoints.
  • Use custom CSS when a style is repeated or needs a meaningful name.

In short

Utilities are quick tools. Use them where they keep the HTML understandable.
