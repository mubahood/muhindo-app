Lesson 7.1

Modals

How it works

A modal opens a dialog above the current page. It is useful for a short task or piece of information that needs attention.

Example

Open a quick view modal

Rice, 5 kg

A pantry staple. $8.00

Code for this example

HTML

<button class="btn btn-primary" data-bs-toggle="modal" data-bs-target="#quickViewDemo">
  Quick view rice
</button>
<div class="modal fade" id="quickViewDemo" tabindex="-1" aria-labelledby="quickViewTitle" aria-hidden="true">
  <div class="modal-dialog">
    <div class="modal-content">
      <div class="modal-header">
        <h2 class="modal-title fs-5" id="quickViewTitle">
          Rice, 5 kg
        </h2>
        <button class="btn-close" data-bs-dismiss="modal" aria-label="Close">
        </button>
      </div>
      <div class="modal-body">
        A pantry staple.
        <strong>
          $8.00
        </strong>
      </div>
      <div class="modal-footer">
        <button class="btn btn-secondary" data-bs-dismiss="modal">
          Close
        </button>
        <button class="btn btn-primary">
          Shop now
        </button>
      </div>
    </div>
  </div>
</div>

When should you use this?

Use a modal for a quick product view or confirmation. Do not put a long form or a whole page inside one.

Key points

  • The trigger target must match the modal id.
  • Give the modal a title and an accessible label.
  • Make sure the user can close it.

In short

A modal should stay focused, brief and easy to dismiss.

Try it yourself

Change the trigger and modal title. Confirm the id and data-bs-target match.
