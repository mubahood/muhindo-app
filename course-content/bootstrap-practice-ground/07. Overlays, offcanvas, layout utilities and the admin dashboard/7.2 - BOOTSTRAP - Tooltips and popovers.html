Lesson 7.2

Tooltips and popovers

How it works

A tooltip shows a short hint on hover or keyboard focus. A popover opens a slightly larger piece of information after activation.

Example

Point to a helpful hint

Code for this example

HTML

<button class="btn btn-outline-secondary me-2" data-bs-toggle="tooltip" title="We accept cash, card and mobile money">
  Payment options
</button>
<button class="btn btn-outline-primary" data-bs-toggle="popover" title="Collect in store" data-bs-content="Choose Central, Northgate or Lakeside at checkout.">
  Click and collect
</button>

Initialize the tooltip and popover

document.querySelectorAll('[data-bs-toggle="tooltip"]').forEach(element => {
  new bootstrap.Tooltip(element);
});

document.querySelectorAll('[data-bs-toggle="popover"]').forEach(element => {
  new bootstrap.Popover(element);
});

When should you use this?

Use a tooltip for a brief label and a popover for a small explanation. Keep important instructions visible in the page.

Key points

  • Bootstrap needs JavaScript initialization for both.
  • Tooltips should not contain essential information.
  • Use buttons or links as interactive triggers.

In short

Hints can help, but a page should still make sense without them.

Try it yourself

Hover or focus for the tooltip; click for the popover. Add clear initialisation in practice.js.
