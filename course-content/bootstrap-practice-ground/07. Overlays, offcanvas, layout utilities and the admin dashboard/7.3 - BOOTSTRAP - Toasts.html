Lesson 7.3

Toasts

How it works

A toast is a brief status message that appears without blocking the page.

Example

Show a cart confirmation

Marigold Stores
Rice was added to your cart.

Code for this example

HTML

<button class="btn btn-primary" id="toastButton">
  Add to cart
</button>
<div class="toast-container position-fixed bottom-0 end-0 p-3">
  <div id="cartToast" class="toast" role="status" aria-live="polite" aria-atomic="true">
    <div class="toast-header">
      <strong class="me-auto">
        Marigold Stores
      </strong>
      <button class="btn-close" data-bs-dismiss="toast" aria-label="Close">
      </button>
    </div>
    <div class="toast-body">
      Rice was added to your cart.
    </div>
  </div>
</div>

Show the toast after the button is clicked

const button = document.querySelector("#toastButton");
const toast = document.querySelector("#cartToast");

button.addEventListener("click", () => {
  bootstrap.Toast.getOrCreateInstance(toast).show();
});

When should you use this?

Use a toast to confirm a small action, such as adding an item to a cart.

Key points

  • Show the toast after the action succeeds.
  • Use a suitable live region so assistive technology can announce it.
  • Do not rely on a toast for critical information.

In short

A toast confirms an action without interrupting the current task.

Try it yourself

Connect the button to show the toast. Keep the status announcement polite.
