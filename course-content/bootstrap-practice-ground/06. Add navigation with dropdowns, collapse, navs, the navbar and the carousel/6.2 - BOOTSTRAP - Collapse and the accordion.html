Lesson 6.2

Collapse and the accordion

How it works

Collapse hides or reveals a section. An accordion uses collapse panels to show one or more answers in a group.

Example

Reveal a delivery answer

Orders arrive within two working days.

Yes, choose a branch at checkout.

Code for this example

HTML

<p>
  <button class="btn btn-outline-primary" data-bs-toggle="collapse" data-bs-target="#deliveryInfo" aria-expanded="false" aria-controls="deliveryInfo">
    Delivery details
  </button>
</p>
<div class="collapse" id="deliveryInfo">
  <div class="card card-body">
    Orders arrive within two working days.
  </div>
</div>
<div class="accordion mt-3" id="faq">
  <div class="accordion-item">
    <h3 class="accordion-header">
      <button class="accordion-button collapsed" data-bs-toggle="collapse" data-bs-target="#answer" aria-expanded="false" aria-controls="answer">
        Can I collect my order?
      </button>
    </h3>
    <div id="answer" class="accordion-collapse collapse" data-bs-parent="#faq">
      <div class="accordion-body">
        Yes, choose a branch at checkout.
      </div>
    </div>
  </div>
</div>

When should you use this?

Use collapse for extra details that are useful but do not need to stay visible. Use an accordion for a short FAQ.

Key points

  • The trigger target must match the panel id.
  • Update aria-controls and aria-expanded.
  • Keep the trigger text clear about what will open.

In short

A correct target connects the control to the content it reveals.

Try it yourself

Change the trigger text and answer. Check that every target id matches exactly.
