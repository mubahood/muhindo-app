Lesson 6.3

Navs and tabs

How it works

Navs arrange related navigation links. Tabs use buttons to switch between content panels on the same page.

Example

Switch between product details

A useful everyday product.
Store in a cool, dry place.

Code for this example

HTML

<ul class="nav nav-tabs" id="detailsTab" role="tablist">
  <li class="nav-item" role="presentation">
    <button class="nav-link active" data-bs-toggle="tab" data-bs-target="#description" type="button" role="tab">
      Description
    </button>
  </li>
  <li class="nav-item" role="presentation">
    <button class="nav-link" data-bs-toggle="tab" data-bs-target="#storage" type="button" role="tab">
      Storage
    </button>
  </li>
</ul>
<div class="tab-content border border-top-0 p-3">
  <div class="tab-pane fade show active" id="description" role="tabpanel">
    A useful everyday product.
  </div>
  <div class="tab-pane fade" id="storage" role="tabpanel">
    Store in a cool, dry place.
  </div>
</div>

When should you use this?

Use tabs for short sets of related details, such as product description, storage and reviews.

Key points

  • Each tab target must match one panel id.
  • Mark the selected tab as active.
  • Use links for navigation to another page.

In short

Tabs switch local content. Ordinary links take people somewhere else.
