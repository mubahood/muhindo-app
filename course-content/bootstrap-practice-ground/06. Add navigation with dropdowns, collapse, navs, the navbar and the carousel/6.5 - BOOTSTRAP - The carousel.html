Lesson 6.5

The carousel

How it works

A carousel shows one item from a set at a time. Bootstrap controls can move between the items.

Example

Rotate through three promotions

Fresh picks this week

Good food for your table.

Ready for school

Find books and supplies.

Code for this example

HTML

<div id="promoCarousel" class="carousel slide" data-bs-ride="carousel">
  <div class="carousel-indicators">
    <button type="button" data-bs-target="#promoCarousel" data-bs-slide-to="0" class="active" aria-current="true" aria-label="Slide 1">
    </button>
    <button type="button" data-bs-target="#promoCarousel" data-bs-slide-to="1" aria-label="Slide 2">
    </button>
  </div>
  <div class="carousel-inner rounded">
    <div class="carousel-item active">
      <div class="p-5 bg-success-subtle">
        <h3 class="h4">
          Fresh picks this week
        </h3>
        <p class="mb-0">
          Good food for your table.
        </p>
      </div>
    </div>
    <div class="carousel-item">
      <div class="p-5 bg-warning-subtle">
        <h3 class="h4">
          Ready for school
        </h3>
        <p class="mb-0">
          Find books and supplies.
        </p>
      </div>
    </div>
  </div>
  <button class="carousel-control-prev" type="button" data-bs-target="#promoCarousel" data-bs-slide="prev" aria-label="Previous">
    <span class="carousel-control-prev-icon">
    </span>
  </button>
  <button class="carousel-control-next" type="button" data-bs-target="#promoCarousel" data-bs-slide="next" aria-label="Next">
    <span class="carousel-control-next-icon">
    </span>
  </button>
</div>

When should you use this?

Use a carousel for a small set of important promotions. Do not hide essential information in slides.

Key points

  • One carousel item must start with active.
  • Every control and indicator targets the carousel id.
  • Give each slide a clear label or heading.

In short

Carousels need working controls and content that remains easy to find.

Try it yourself

Add one slide and its indicator. Keep a clear visible heading on every slide.
