Lesson 6.4

The navbar

How it works

A navbar is a shared navigation area. The expand classes set the width at which its links collapse into a menu button.

Example

Make a menu that collapses on a phone

Marigold
  • Products
  • About

Code for this example

HTML

<nav class="navbar navbar-expand-lg bg-body-tertiary border rounded px-3">
  <a class="navbar-brand" href="../index.html">
    Marigold
  </a>
  <button class="navbar-toggler" type="button" data-bs-toggle="collapse" data-bs-target="#navPractice" aria-controls="navPractice" aria-expanded="false" aria-label="Toggle navigation">
    <span class="navbar-toggler-icon">
    </span>
  </button>
  <div class="collapse navbar-collapse" id="navPractice">
    <ul class="navbar-nav ms-auto">
      <li class="nav-item">
        <a class="nav-link" href="#">
          Products
        </a>
      </li>
      <li class="nav-item">
        <a class="nav-link" href="#">
          About
        </a>
      </li>
    </ul>
  </div>
</nav>

When should you use this?

Use a navbar for the main links people need across the pages of a site.

Key points

  • The toggler target must match the collapsible element id.
  • Use navbar-expand-* to choose the expand breakpoint.
  • Give the menu button an accessible label.

In short

Keep the main navigation short and make the small-screen toggle work.

Try it yourself

Resize the page and open the menu. Add a Contact link and check the target id.
