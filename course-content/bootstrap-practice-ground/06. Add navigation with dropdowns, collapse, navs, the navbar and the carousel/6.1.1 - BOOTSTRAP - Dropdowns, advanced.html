Lesson 6.1.1

Dropdowns, advanced

How it works

A dropdown does not have to open downwards, and it does not have to hold only links. Direction classes on the wrapper change where the menu appears, and any markup you like can go inside the menu, including a small form.

Example

A dropdown that opens upward

  • Orders
  • Sign out

Code for this example

HTML

<div class="btn-group dropup">
  <button class="btn btn-secondary dropdown-toggle" data-bs-toggle="dropdown">
    Account
  </button>
  <ul class="dropdown-menu">
    <li><a class="dropdown-item" href="#">Orders</a></li>
  </ul>
</div>

When should you use this?

Use dropup for a menu near the bottom of the page, where a normal dropdown would open off the screen. Use dropend inside a sidebar, where there is room to the side but not below.

Key points

  • dropup, dropend and dropstart go on the wrapper, not the menu.
  • dropdown-menu-end aligns the menu to the right edge of the button.
  • A form inside a menu needs a click handler that stops the menu closing.
  • The bundle must be loaded or none of this opens at all.

In short

Direction classes keep a menu on screen; the menu itself can hold whatever the page needs.
