Lesson 9.2

Your own theme with CSS variables

How it works

CSS variables store reusable values such as brand colors. Bootstrap also uses variables for many component colors.

Example

Give Marigold a theme colour

Marigold colour sample

A small custom rule can make the site feel consistent.

Code for this example

HTML

<div class="theme-card p-4 rounded-3">
  <h3 class="h5">
    Marigold colour sample
  </h3>
  <p class="mb-3">
    A small custom rule can make the site feel consistent.
  </p>
  <button class="btn btn-marigold">
    Shop Marigold
  </button>
</div>

CSS variables for the theme

:root {
  --marigold-rust: #b5541c;
}

.theme-card {
  background: var(--marigold-rust);
}

When should you use this?

Use variables when the same theme color or size appears in several places.

Key points

  • Define a variable with a name that begins with --.
  • Read a variable with var(--name).
  • Some Bootstrap components use different variables for their colors.

In short

A small set of variables makes a theme easier to adjust consistently.
