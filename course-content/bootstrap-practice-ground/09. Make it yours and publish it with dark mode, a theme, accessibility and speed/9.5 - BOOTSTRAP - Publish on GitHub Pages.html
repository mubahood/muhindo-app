Lesson 9.5

Publish on GitHub Pages

How it works

GitHub Pages publishes a static website from a GitHub repository. HTML, CSS, JavaScript and images can be served this way.

Example

Prepare the site for publishing

Before you publish: test links, commit your changes, then enable GitHub Pages for the repository.

When should you use this?

Use GitHub Pages to share a static project or portfolio site.

Key points

  • Check that links use paths that work from the repository.
  • Commit and push the files you want to publish.
  • GitHub Pages does not run PHP or a database.

In short

A published page is only as complete as the files and paths in the repository.

Try it yourself

Use a relative asset path and check it on a nested page. Commit a small change before publishing.
