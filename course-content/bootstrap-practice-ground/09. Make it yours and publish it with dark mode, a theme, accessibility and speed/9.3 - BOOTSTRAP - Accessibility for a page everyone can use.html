Lesson 9.3

Accessibility for a page everyone can use

How it works

Accessibility means people with different abilities can understand and use your page. Labels, headings, contrast and keyboard support all help.

Example

Check keyboard access and labels

Use Tab to move through the controls.

Code for this example

HTML

<form>
  <label class="form-label" for="accessibleSearch">
    Search products
  </label>
  <div class="input-group">
    <input class="form-control" id="accessibleSearch" type="search">
    <button class="btn btn-primary" type="submit">
      Search
    </button>
  </div>
</form>
<p class="small text-secondary mt-3">
  Use Tab to move through the controls.
</p>

When should you use this?

Check accessibility on every page, especially forms, menus, dialogs and icon buttons.

Key points

  • Use semantic HTML and descriptive labels.
  • Check that the page works with a keyboard.
  • Make text and controls easy to see.

In short

Accessible pages are clearer and easier for more people to use.
