Lesson 9.1

Dark mode with colour modes

How it works

Bootstrap color modes use data-bs-theme to apply light or dark colors to a page or part of a page.

Example

Switch the colour mode

The page follows its selected colour mode.

Code for this example

HTML

<div class="d-flex align-items-center gap-3">
  <p class="mb-0">
    The page follows its selected colour mode.
  </p>
  <button class="btn btn-outline-secondary" type="button" id="themeToggle" aria-pressed="false">
    Toggle theme
  </button>
</div>

Switch between light and dark

const button = document.querySelector("#themeToggle");

button.addEventListener("click", () => {
  const root = document.documentElement;
  const dark = root.getAttribute("data-bs-theme") !== "dark";
  root.setAttribute("data-bs-theme", dark ? "dark" : "light");
  button.setAttribute("aria-pressed", String(dark));
});

When should you use this?

Use a theme toggle when visitors benefit from choosing a light or dark display.

Key points

  • Set data-bs-theme to light or dark.
  • Test text, controls and custom colors in both modes.
  • Make the toggle a real button with a clear name.

In short

Dark mode works only when every part of the page remains readable.

Try it yourself

Try data-bs-theme="dark" on the html element and provide a button that switches it.
