Lesson 9.4

Performance for a fast page on a slow phone

How it works

A fast page sends only the files it needs and avoids making the browser wait for large images.

Example

Make an image lighter and responsive

Fast pages help everyone

Use appropriately sized images and avoid loading content the page does not need.

Code for this example

HTML

<div class="row align-items-center g-3">
  <div class="col-sm-5">
    <img class="img-fluid rounded" loading="lazy" width="800" height="800" src="../images/products/rice-5kg.webp" alt="Marigold rice in a five kilogram bag">
  </div>
  <div class="col-sm-7">
    <h3 class="h5">
      Fast pages help everyone
    </h3>
    <p class="mb-0">
      Use appropriately sized images and avoid loading content the page does not need.
    </p>
  </div>
</div>

When should you use this?

Optimize images and page resources when people may have slow connections or limited data.

Key points

  • Use suitable image dimensions and formats.
  • Lazy-load images that start below the first screen.
  • Include width and height to reduce layout movement.

In short

Smaller, well-sized assets help pages load smoothly on slower devices.

Try it yourself

Inspect image size and loading. Keep width and height dimensions to reduce layout movement.
