Lesson 3.1

Containers and breakpoints

How it works

A container sets a responsive maximum width for page content. A fluid container stays as wide as its parent.

Example

Compare container widths

container
container-fluid

Code for this example

HTML

<div class="container mb-2">
  <div class="p-2 bg-primary-subtle rounded">
    container
  </div>
</div>
<div class="container-fluid">
  <div class="p-2 bg-success-subtle rounded">
    container-fluid
  </div>
</div>

When should you use this?

Use a regular container for text and page content. Use a fluid container for a section that should span the screen.

Key points

  • Containers add horizontal space around content.
  • Their maximum width changes at Bootstrap breakpoints.
  • A full-width background can sit outside a regular container.

In short

Choose a container based on how wide the content should feel.
