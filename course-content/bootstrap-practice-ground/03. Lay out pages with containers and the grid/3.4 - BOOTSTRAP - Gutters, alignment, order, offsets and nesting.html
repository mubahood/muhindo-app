Gutters, alignment, order, offsets and nesting

How it works

Grid utilities adjust the space and position of columns. Gutters create gaps, alignment positions items, and order changes their visual sequence.

When should you use this?

Use these utilities when a simple grid needs different spacing or alignment at one screen size.

Key points

  • Gutters control the gap between columns.
  • Order classes can change visual order at a breakpoint.
  • Keep the reading order sensible for keyboard and screen reader users.

In short

Use grid utilities to refine a layout without losing a clear reading order.
