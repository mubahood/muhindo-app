Lesson 3.2

Rows and columns, the grid basics

How it works

Bootstrap divides a row into twelve columns. Column classes tell each item how much of that row to use.

Example

Make twelve columns add up

8 columns
4 columns

Code for this example

HTML

<div class="row g-2 text-center">
  <div class="col-8">
    <div class="p-3 bg-primary-subtle rounded">
      8 columns
    </div>
  </div>
  <div class="col-4">
    <div class="p-3 bg-warning-subtle rounded">
      4 columns
    </div>
  </div>
</div>

When should you use this?

Use rows and columns to place content side by side, such as product information beside a photo.

Key points

  • Put columns directly inside a row.
  • The numbered columns in one row should add up to twelve.
  • Use gutters to add space between columns.

In short

Rows group columns, and column numbers describe their share of the row.

Try it yourself

Change the column split to 7 and 5. Keep the two numbers adding to twelve.
