Lesson 3.5

Spacing utilities and the home page hero

How it works

Spacing utilities add margin or padding with short class names. For example, p-3 adds padding and mb-3 adds space below an element.

Example

Give the hero room to breathe

Welcome to Marigold

Everyday shopping, made easy.

Find the things your home needs.

Code for this example

HTML

<section class="p-4 p-md-5 bg-success-subtle rounded-4">
  <p class="small text-uppercase mb-2">
    Welcome to Marigold
  </p>
  <h2 class="display-6">
    Everyday shopping, made easy.
  </h2>
  <p class="lead mb-3">
    Find the things your home needs.
  </p>
  <button class="btn btn-primary">
    Shop now
  </button>
</section>

When should you use this?

Use spacing utilities to create consistent gaps around a section, heading or button.

Key points

  • m means margin and p means padding.
  • A side letter can limit the spacing to one direction.
  • Responsive spacing classes can change at a breakpoint.

In short

Use a few consistent spacing classes instead of adding random gaps.
