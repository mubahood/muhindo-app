Lesson 3.3

Responsive columns at every grid tier

How it works

Responsive column classes change a column width at a named breakpoint. A class without a breakpoint applies at every width.

Example

Choose a different layout at each width

  <div class="col-12 col-sm-6 col-lg-4">
    <div class="p-3 border rounded">

When should you use this?

Use responsive columns for product grids, feature lists and layouts that need more space on a larger screen.

Key points

  • Bootstrap breakpoints use sm, md, lg, xl and xxl.
  • A class such as col-md-6 applies from the medium breakpoint upward.
  • Combine classes when the layout changes more than once.

In short

Choose the column count for each screen size and test the actual breakpoints.
