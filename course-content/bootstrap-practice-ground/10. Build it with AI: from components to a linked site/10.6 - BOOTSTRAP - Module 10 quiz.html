Lesson 10.6

Module 10 quiz

Example

Answer each question in your own words. Check the notes after you finish.

  1. Why write .github/copilot-instructions.md before the first HTML file?
    • a) It makes the assistant faster
    • b) It sets the version and house rules once, so answers stop drifting between Bootstrap 4 and 5
    • c) It is required by VS Code
    • d) It replaces the need to check the output
  2. You ask for the second page and the assistant gives it a slightly different navbar. What is the correct instruction?
    • a) Accept it, both are valid Bootstrap
    • b) Copy the navbar from index.html exactly, character for character, and change only the active link
    • c) Ask it to redesign both navbars to match
    • d) Move the navbar into a JavaScript file
  3. Which prompt will give you a page you can actually check?
    • a) Build me a professional portfolio website
    • b) Make a modern responsive homepage with good design
    • c) Build four named sections in order, each naming the Bootstrap classes it should use
    • d) Build a homepage like Apple
  4. Why does the sign in page not get the admin sidebar?
    • a) Sidebars are slow
    • b) Nobody is signed in yet, so there is nothing to navigate; say which pages share which layout or the assistant will guess
    • c) Bootstrap does not allow it
    • d) It would break the offcanvas
  5. An AI status column shows green, amber and grey dots with no words. What is wrong?
    • a) Nothing, the colours are clear
    • b) Colour alone carries the meaning, so the status word must be in the badge too
    • c) The badges need to be bigger
    • d) It should use a progress bar
  6. What should you say on camera when the admin project is finished?
    • a) That it is a working admin system
    • b) That it is layout only: nothing saves, the numbers do not change, and courses 3 and 5 make it work
    • c) That it needs a database licence
    • d) Nothing, the learner can see it
Show answer notes
  1. b. The rules file is read every time, so you stop repeating yourself and the drift stops. You still check.
  2. b. Copying keeps one site. Redesigning both doubles the work and the risk.
  3. c. Named parts can be checked one at a time. A whole site cannot.
  4. b. Layouts belong to states. Say so in the prompt.
  5. b. Anyone who cannot tell the colours apart gets nothing. The word goes in the badge.
  6. b. Naming the limit stops learners expecting behaviour that is not there.
