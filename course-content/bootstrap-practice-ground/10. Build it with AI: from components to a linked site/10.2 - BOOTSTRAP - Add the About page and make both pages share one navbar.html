Lesson 10.2

Add the About page and make both pages share one navbar

How it works

The second page is where an assistant drifts most. Asked for a page on its own it will redesign the navbar, and the site stops looking like one site.

Prompts for this lesson

Copy each prompt in order. Run one, check the answer against the checklist below it, then move on. Never paste the next prompt until the last one is correct.

1. Copy the shell, do not redesign it

Create about.html in the same folder as index.html.
Copy the navbar and the footer from index.html exactly as they are, character for character.
Do not redesign them. Do not rename any class. Do not add or remove any link.
The only change you may make is which link carries the active class and aria-current="page":
on this page it is About, and Home must no longer have either.

Check before you keep it: Open both files side by side. The navbar markup should be identical apart from the two active attributes.

2. The About content, in named parts

Between the navbar and the footer in about.html, add these parts in order.

1. A page header: container py-5, an h1 "About me" and one lead paragraph.

2. An intro row: container, row with g-4 and align-items-center.
   Left column col-12 col-md-5 holding an image with class img-fluid rounded and real alt text.
   Right column col-12 col-md-7 holding three short paragraphs.

3. A skills list: an h2 then a list-group list-group-flush.
   Each item uses d-flex justify-content-between align-items-center
   with the skill name on the left and a badge on the right.

4. A short history: an h2 then three cards in a row row-cols-1 row-cols-md-3 g-3,
   each card holding a year, a role title and one line of description.

Check before you keep it: At 360 pixels the image sits above the text, not beside it. Every image has alt text that is not the filename.

  </p>
</div>

When should you use this?

Every time you add a page to a project that already has a header and footer.

Key points

  • Tell it to copy the navbar and footer character for character.
  • Change only which link carries active and aria-current.
  • Use plain relative paths, because a leading slash breaks on GitHub Pages.

In short

Name the first page as the source of truth, or every new page becomes a new design.

Try it yourself

Activate both buttons. Search the old example for data-toggle and data-target, then compare it with the working Bootstrap 5 version.
