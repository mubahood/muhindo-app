Lesson 11.6

Module 11 quiz

Example

Answer each question in your own words. Check the notes after you finish.

  1. Why is the final project a school site rather than the Marigold shop?
    • a) Schools are easier
    • b) Nothing from the first nine modules can be copy pasted into it, so it tests what you actually know
    • c) Shops cannot be themed
    • d) It is shorter
  2. Before the first prompt in lesson 53, what do you write down?
    • a) The colour codes
    • b) Which pages share the public header, which share the admin shell, and which share neither
    • c) The list of Bootstrap components
    • d) The GitHub repository name
  3. An admin page works in the editor and loses its stylesheet once published. What is the likely cause?
    • a) GitHub Pages does not allow subfolders
    • b) The page is one folder down and the link is missing ../
    • c) Bootstrap must be installed
    • d) The CSS file is too large
  4. You set --bs-primary to the navy, but the buttons are still Bootstrap blue. Why?
    • a) The file is cached
    • b) Buttons use their own component variables such as --bs-btn-bg, which must be set on .btn-primary
    • c) Navy is not a valid colour
    • d) You need Sass
  5. Which accessibility check finds the most problems on the admissions page?
    • a) Running Lighthouse
    • b) Tabbing through the whole form with the keyboard only
    • c) Checking the colour contrast
    • d) Validating the HTML
  6. What is the habit the course ends on?
    • a) Write better prompts
    • b) Use AI only for small things
    • c) The assistant drafts, you check the version and the classes, you test at three widths, and your name goes on the result
    • d) Avoid AI for layout
Show answer notes
  1. b. A final project that can be copied from your own earlier work tests nothing.
  2. b. Every later prompt refers back to those three groups. Without them the assistant guesses.
  3. b. Paths from a subfolder have to go up a level first.
  4. b. The same rule as module 9. Theme the component, not just the palette.
  5. b. Lighthouse cannot tell whether the tab order makes sense. Your keyboard can.
  6. c. Useful and accountable at the same time, which is the whole course in one line.
