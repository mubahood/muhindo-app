Lesson 11.2

Prompt the home page and the about page

How it works

Backgrounds and overlays are where an assistant reaches for an inline style, which cannot be themed, overridden or switched to dark mode later.

Example

A hero that themes without an inline style

Kestrel Ridge Secondary School

Learning that lasts.

Founded in 1998. Three streams. Three hundred students.

Apply now

Prompts for this lesson

Copy each prompt in order. Run one, check the answer against the checklist below it, then move on. Never paste the next prompt until the last one is correct.

1. The home page, in five named parts

In index.html build these five parts in order, using only Bootstrap 5.3 classes.

1. Navbar: navbar navbar-expand-lg sticky-top, background using --kr-navy applied
   through a class in css/style.css and not an inline style.
   Brand "Kestrel Ridge Secondary School". Links Home, About, News, Admissions,
   then a btn btn-warning "Apply now" linking to admissions.html.
   It collapses behind a navbar-toggler below lg. Home is active with aria-current="page".

2. Hero: a section with a background photo and a dark overlay for text contrast,
   both set in css/style.css using a class, never inline.
   An h1, one lead line, and two buttons.

3. Three cards: row row-cols-1 row-cols-md-3 g-4 for Academics, Sport and Boarding.
   Each card has a Bootstrap Icon, an h3 and two lines of text. Equal heights.

4. Latest news: an h2 and a row of three cards, each with a date in a small muted line,
   an h3 title, two lines of text and a "Read more" link to article.html.

5. Footer: three columns. Contact details with icons, a short list of links,
   and a copyright line with the year inside span id="year".

Check before you keep it: Search the file for the word style=. If the hero used an inline style, ask again and tell it to use a class in css/style.css. An inline style cannot be themed or switched to dark mode later.

2. The about page

Create about.html. Copy the navbar and footer from index.html exactly,
character for character, and set the active link to About.

Between them add:
1. A page header with an h1 and one lead line.
2. A history row: col-12 col-lg-7 with three paragraphs covering the school
   founded in 1998 and growing to three hundred students, and col-12 col-lg-5
   with an image, img-fluid rounded, with real alt text.
3. Leadership: a row row-cols-1 row-cols-sm-2 row-cols-lg-4 g-4 with four cards.
   Mrs. Grace Okello is the head teacher; invent three more staff names and roles.
   Each card has a photo placeholder, a name and a role.
4. A facts strip: four numbers with short labels, in a row that stacks on phones.
   Founded 1998, 300 students, 3 streams, 24 staff.

Check before you keep it: Both pages at 360, 768 and 1280. Then click Home from About and About from Home. Commit with a message saying what you built.

When should you use this?

Any hero, banner or section with a background image or a colour wash.

Key points

  • Ban inline styles in the rules file and enforce it.
  • Ask again rather than patching the answer by hand when the fix is structural.
  • Commit at the end of every lesson with a message that says what was built.

In short

A page that cannot be themed later was built wrong today, even if it looks right.

Try it yourself

Prompt for this hero and check one thing: if the answer uses style="background-image:...", ask again and tell it to use a class in style.css.
