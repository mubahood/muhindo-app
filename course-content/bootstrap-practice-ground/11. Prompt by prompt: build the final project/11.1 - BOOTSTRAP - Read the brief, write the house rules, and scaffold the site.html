Lesson 11.1

Read the brief, write the house rules, and scaffold the site

How it works

A page plan is three lists: pages that share the public header, pages that share the admin shell, and pages that share neither. Every later prompt points back at it.

Example

Group the pages before you prompt

Group 1

Public header and footer

  • index.html
  • about.html
  • news.html
  • article.html
  • admissions.html

Group 2

Admin shell

  • admin/index.html
  • admin/news-list.html
  • admin/news-form.html

Group 3

Neither

  • admin/login.html

Prompts for this lesson

Copy each prompt in order. Run one, check the answer against the checklist below it, then move on. Never paste the next prompt until the last one is correct.

1. The brief you are working from

Kestrel Ridge Secondary School needs a website.

Pages: a home page, an about page, a news list, a single news article,
an admissions form, and a small admin area behind a sign in page.
Brand colours: navy #1F3A5F and gold #C8963E.
Head teacher: Mrs. Grace Okello. Phone +000 555 0142. Email info@kestrelridge.example.
Three hundred students. Founded 1998. Three streams: Sciences, Arts and Vocational.

Everything in this brief is invented. Never put a real person's photo,
a real phone number or a real address in practice work.

Check before you keep it: Read it twice before you prompt for anything. You cannot check an answer against a brief you have not read.

2. Your page plan, written before any prompt

Group 1, pages sharing the public header and footer:
  index.html, about.html, news.html, article.html, admissions.html

Group 2, pages sharing the admin shell:
  admin/index.html, admin/news-list.html, admin/news-form.html

Group 3, pages sharing neither:
  admin/login.html

Check before you keep it: Write this out yourself before prompting. Every prompt in this module refers back to it, and the assistant cannot guess it.

3. The scaffold, files only

Create these files. Each one contains only the doctype, html lang="en",
a head with charset, viewport and a title, the Bootstrap 5.3 CSS link from jsDelivr,
then css/style.css, and the Bootstrap bundle script before the closing body tag.

index.html, about.html, news.html, article.html, admissions.html,
admin/login.html, admin/index.html, admin/news-list.html, admin/news-form.html

Also create css/style.css containing only this:
:root { --kr-navy: #1F3A5F; --kr-gold: #C8963E; }

Important: the four files inside the admin folder are one level down,
so their links to Bootstrap and to css/style.css must use ../ correctly.
Write no page content anywhere.

Check before you keep it: Open admin/login.html in the browser. If it looks like plain unstyled text, the ../ paths are wrong. Fix that now, not after you have built nine pages on top of it.

When should you use this?

Before the first line of a project, especially one an assistant will help build.

Key points

  • Write the groups down before prompting.
  • Create the files empty and check the paths first.
  • Put the brand colours in :root as variables from the start.

In short

Plan the structure yourself; the assistant fills it in, it does not decide it.

Try it yourself

Write your own three groups for the Kestrel Ridge brief before you prompt for a single page. Every later prompt refers back to this list.
