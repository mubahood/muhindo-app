When should you use this?

At the end of the course, and whenever you present this work to anyone.

Key points

  • You can tell Bootstrap 5 from older code in seconds.
  • You test at 360, 768 and 1280 before you keep anything.
  • Your name goes on the result, whoever or whatever typed it.

In short

You learned Bootstrap so you could tell when an assistant is wrong, and fix it.
