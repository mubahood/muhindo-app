Lesson 11.1.1

Final project demo, the Marigold shop

How it works

Before you write a single prompt, it helps to see where you are going. This lesson is a tour of the finished Marigold shop: every page, how they link together, how the layout behaves on a phone, and what the admin side looks like behind the sign-in page.

Example

What the finished site contains

Home — hero, featured products, footer
About — story, team, shared navbar
News and article — list page and a single post
Admissions form — validated, with floating labels
Admin — sign in, shell, dashboard, list

Code for this example

  index.html      home
  about.html      about
  news.html       article list
  article.html    single article
  apply.html      admissions form
  admin/          sign in, shell, dashboard, list

When should you use this?

Watch this once before Lesson 11.1, and again whenever a prompt gives you something that does not look right. Knowing the target is what lets you tell a good result from a bad one.

Key points

  • Every page uses the same navbar and footer.
  • Nothing on the site needs custom CSS beyond a short theme file.
  • The admin side reuses the shell you built in Module 10.
  • The whole site is published on GitHub Pages at the end.

In short

See the finished site first, then build it one prompt at a time.

Try it yourself

List the pages above in your own notes, and write one sentence per page describing what it must contain.
