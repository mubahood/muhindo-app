Lesson 2.4

The check habit, four checks before you keep AI code

How it works

Checking code before keeping it prevents small mistakes from spreading through a project.

Example

Use four checks before keeping code

  1. Version
  2. Class names
  3. Phone width
  4. Console

When should you use this?

Use the same checks after every AI suggestion and whenever a component behaves unexpectedly.

Key points

  • Confirm the version.
  • Check the class and data attribute names.
  • Test at phone, tablet and laptop widths.
  • Look for browser Console errors.

In short

Read it, check it, test it, then decide whether to keep it.
