Lesson 2.2

Set up GitHub Copilot Free in VS Code

How it works

GitHub Copilot can suggest code while you type in VS Code. A suggestion is only a draft until you understand and test it.

Example

Draft a button, then inspect it

Code for this example

HTML

<button class="btn btn-primary">
  Shop now
</button>

When should you use this?

Use Copilot to draft a small section, such as one product card or a labeled input.

Key points

  • Read a suggestion before accepting it.
  • Ask for one small change at a time.
  • Check the result in the browser.

In short

Accept only code you can explain and verify.

Try it yourself

Use Copilot to suggest one button variation. Check the class names and preview before accepting.
