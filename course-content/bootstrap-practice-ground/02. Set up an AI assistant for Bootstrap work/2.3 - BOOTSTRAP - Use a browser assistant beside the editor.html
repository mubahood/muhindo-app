Lesson 2.3

Use a browser assistant beside the editor

How it works

A browser assistant is useful for a second explanation or a first draft. You can keep your code editor open while you ask a question.

Example

Compare two explanations

Assistant A: draft an alert.
Assistant B: explain the alert classes.

When should you use this?

Use it when you need a class explained or a small example to compare with the Bootstrap docs.

Key points

  • Describe the exact page task.
  • State the Bootstrap version.
  • Do not paste private information into an assistant.

In short

A second opinion can help, but the page and documentation decide whether the answer works.

Try it yourself

Ask a browser assistant to explain one class. Compare its answer with the Bootstrap documentation.
