Lesson 4.1

Typography with headings, display text, lead and lists

How it works

Bootstrap typography classes set text size and emphasis. HTML headings still describe the structure of the page.

Example

Give each line the right importance

Fresh goods for every day

A short introduction to the shop.

  • Helpful service
  • Three local branches

Code for this example

HTML

<h2 class="display-6">
  Fresh goods for every day
</h2>
<p class="lead">
  A short introduction to the shop.
</p>
<ul>
  <li>
    Helpful service
  </li>
  <li>
    Three local branches
  </li>
</ul>

When should you use this?

Use heading classes to style a heading without changing its HTML level. Use lead for a short introduction.

Key points

  • Keep heading levels in a logical order.
  • Use display classes for large headings.
  • Use lists for groups of related items.

In short

Choose HTML for meaning and Bootstrap classes for appearance.
