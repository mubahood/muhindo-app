Lesson 4.3

Tables and the cart page

How it works

An HTML table presents related information in rows and columns. Bootstrap table classes add styling, and a responsive wrapper helps wide tables on small screens.

Example

Build a small cart table

ItemQtyPrice
Rice, 5 kg1$8.00
Tea leaves2$6.00

Code for this example

HTML

<div class="table-responsive">
  <table class="table table-striped align-middle">
    <thead>
      <tr>
        <th scope="col">
          Item
        </th>
        <th scope="col">
          Qty
        </th>
        <th scope="col" class="text-end">
          Price
        </th>
      </tr>
    </thead>
    <tbody>
      <tr>
        <td>
          Rice, 5 kg
        </td>
        <td>
          1
        </td>
        <td class="text-end">
          $8.00
        </td>
      </tr>
      <tr>
        <td>
          Tea leaves
        </td>
        <td>
          2
        </td>
        <td class="text-end">
          $6.00
        </td>
      </tr>
    </tbody>
  </table>
</div>

When should you use this?

Use a table for data with clear rows and columns, such as items, quantities and prices in a cart.

Key points

  • Use thead for column headings and tbody for table rows.
  • Use th for headings and scope to identify their direction.
  • Wrap a wide table in table-responsive.

In short

Use tables for data, not for laying out a whole page.
