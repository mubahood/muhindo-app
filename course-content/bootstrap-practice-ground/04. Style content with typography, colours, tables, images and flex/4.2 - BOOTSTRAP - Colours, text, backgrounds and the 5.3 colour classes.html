Lesson 4.2

Colours, text, backgrounds and the 5.3 colour classes

How it works

Bootstrap has color classes for text and backgrounds. The color names communicate intent, such as success or warning.

Example

Use colour to show meaning

Order received successfully.

Delivery is available in your area.

Low stock

Code for this example

HTML

<div class="alert alert-success">
  Order received successfully.
</div>
<p class="text-secondary">
  Delivery is available in your area.
</p>
<span class="badge text-bg-warning">
  Low stock
</span>

When should you use this?

Use a color utility to make status or emphasis clear, while keeping enough contrast to read the text.

Key points

  • Text colors and background colors use different class names.
  • Use text-bg-* for text with a matching background color.
  • Do not use color as the only way to communicate meaning.

In short

Color can help explain a message, but the words must still make its meaning clear.
