Lesson 4.5

Flex utilities to line things up

How it works

Flex utilities arrange items along a row or column and control their alignment and spacing.

Example

Line up a price and an action

Rice, 5 kg
$8.00

Code for this example

HTML

<div class="d-flex align-items-center justify-content-between border rounded p-3">
  <div>
    <strong>
      Rice, 5 kg
    </strong>
    <div class="text-secondary">
      $8.00
    </div>
  </div>
  <button class="btn btn-primary">
    Shop now
  </button>
</div>

When should you use this?

Use flex for small groups of items, such as a product name and price beside an action button.

Key points

  • d-flex turns an element into a flex container.
  • justify-content positions items along the main direction.
  • align-items positions items across that direction.

In short

Flex is useful for lining up related items without adding unnecessary columns.

Try it yourself

Use flex utilities to align two items vertically and push them to opposite sides.
