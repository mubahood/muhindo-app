Lesson 10.2

Catch Bootstrap 4 code in a Bootstrap 5 page

How it works

Bootstrap 5 changed several class names and data attributes from Bootstrap 4. Old code may look normal while parts quietly fail.

Example

Compare Bootstrap 4 and 5 syntax

Old Bootstrap 4 markup

It has no Bootstrap 5 trigger.

Bootstrap 5 markup

Bootstrap 5 uses data-bs-* attributes.

Code for this example

HTML

<h4 class="h6">
  Old Bootstrap 4 markup
</h4>
<button class="btn btn-secondary" data-toggle="collapse" data-target="#oldExample">
  This old toggle does not open
</button>
<div class="collapse" id="oldExample">
  <p>
    It has no Bootstrap 5 trigger.
  </p>
</div>
<h4 class="h6 mt-3">
  Bootstrap 5 markup
</h4>
<button class="btn btn-primary" data-bs-toggle="collapse" data-bs-target="#bs5Example" aria-expanded="false" aria-controls="bs5Example">
  Open the Bootstrap 5 panel
</button>
<div class="collapse mt-2" id="bs5Example">
  <p>
    Bootstrap 5 uses data-bs-* attributes.
  </p>
</div>

When should you use this?

Check the version when copying code from an old tutorial or an AI answer.

Key points

  • Bootstrap 5 JavaScript attributes use the data-bs- prefix.
  • Many spacing classes use ms and me instead of ml and mr.
  • Check the current documentation before replacing old code.

In short

Match the code to the Bootstrap version loaded by the page.

Try it yourself

Activate both buttons. Search the old example for data-toggle and data-target, then compare it with the working Bootstrap 5 version.
