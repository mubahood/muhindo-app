Lesson 10.1

Catch an invented class

How it works

A class only changes appearance when a stylesheet defines a rule for it. A class name can sound correct and still do nothing.

Example

Compare a made-up class with a real one

The made-up class text-bold has no Bootstrap style.

The real class fw-bold makes this text bold.

Code for this example

HTML

<p class="text-bold">
  The made-up class text-bold has no Bootstrap style.
</p>
<p class="fw-bold">
  The real class fw-bold makes this text bold.
</p>

When should you use this?

Check any unfamiliar class when an AI answer or tutorial gives you a name you have not seen.

Key points

  • Inspect the element in DevTools.
  • Look for a matching rule in the Styles pane.
  • Check the Bootstrap docs for the class name.

In short

Do not trust a class because its name sounds plausible.

Try it yourself

Inspect both paragraphs in DevTools. Check which class has a matching CSS rule, then verify the real class in the Bootstrap docs.
