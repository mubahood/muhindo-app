# Course 07 ⭐ — WordPress from Zero to Hero

**Tier 1 · Foundations · Level: Absolute beginner · Prerequisites: none · TOP FEATURED**

Not everyone needs to write code to publish on the web. WordPress powers about 40% of
all websites — and it is also a real income skill: many clients simply want a
WordPress site set up and managed well. This short course makes you dangerous with it.

**What you will learn**

- Install and set up a WordPress site from scratch
- Create pages, posts, menus and manage media
- Choose and customise themes and essential plugins
- Keep a WordPress site secure and up to date

## Module 3 — Running a real site (practice module)

Text lessons with screenshots — no video needed:

8. **Essential plugins** — contact form, SEO, caching, backup: one good choice each.
9. **Users and roles** — admin, editor, author: give people only what they need.
10. **Keeping it safe** — updates, strong passwords, backups before changes.

## Final project

Build a complete **small-business website**: home, about, services, blog with two
posts, contact form, custom menu, and your own branding. Deliver the live link (or
screenshots) plus a one-page maintenance plan.

**Quiz ideas:** dashboard scavenger hunt ("where do you change the site title?") ·
posts vs pages true/false · role-matching quiz · practical graded on the checklist.

**Good to know:** when a client needs features WordPress can't do cleanly, that's when
custom development (Courses 10, 12) takes over — you'll know both worlds.
