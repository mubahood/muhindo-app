learning order, simple-English descriptions, example code, quiz ideas, and a real
final project. Video links point primarily to the **Learn It With Muhindo** channel
(@LearnitwithMuhindo), with hand-picked external videos (freeCodeCamp, Mosh, Bro
Code, DevLap, Code With Dary) only where they fill a genuine gap. Lessons that don't
need a video (short concept or practice lessons) deliberately have none.

## Editorial decisions (vs the earlier draft catalog)

1. **"WhatsApp Clone" capstone replaced** by *Flutter Mini-Projects* (Course 21): the
   2021 clone videos are no longer public on the channel; searches surfaced no
   usable originals. The chat concept survives as an FCM extension brief in Course 20.
   Its ⭐ moved to Course 11 (Flutter, from Zero), whose merged content earns it.
2. **The two overlapping e-commerce PHP courses merged** into one strong Course 19
   (the "E-commerce website 2021" material overlaps the Online Shop series almost
   video-for-video).
3. **Courses restructured, not transcribed:** lessons were re-ordered into proper
   learning sequence, retitled in clean simple English, deduplicated across
   playlists, and gaps were filled with either text/practice lessons or verified
   external videos — following the W3Schools topic progressions and Udemy's
   module-project-quiz course shape.

## Link verification note

All Muhindo-channel links were extracted live from the channel's public playlists
(July 2026) and external links were verified via YouTube's oEmbed API — no invented
URLs. A handful of lesson titles could not be read from the playlist data (private
metadata); those lessons carry their playlist's link or their series' deep link so
students always land on real content. If any single video is later made private,
each capstone file also carries its full playlist URL as a fallback.
